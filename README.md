## ✨ Core Features

- **Instant Summaries**: Clean, readable output from any link or raw text.
- **Vibe Score (0–100)**: Quantified "vibe" rating for quick shareability assessment.
- **One-Click Sharing**: Copy or share results instantly to any platform.
- **Zero-Dependency Single File**: Pure HTML5 + CSS + JS. Runs on GitHub Pages, Netlify, Vercel, or locally with zero build step.
- **Dark Cyber Aesthetic**: High-contrast research UI matching the ATSMATRIX visual language.
- **Fast & Addictive**: No AI fluff, just results.

---

## 🔄 How It Works

1. Paste a URL or block of text into the input field.
2. Hit **Summarize**.
3. Get a crisp summary + vibe score (0-100).
4. Share the result instantly.

---

## 💾 Local Setup

```bash
git clone https://github.com/anyel1to/echo.git
cd echo
npm install
npm start
```

Open http://localhost:3000 and start echoing.
