# Echo

Drop a link or text. Get a clean, shareable summary with a vibe score.

Fast. Addictive. No AI fluff.

## How it works
- Paste a URL or block of text
- Hit summarize
- Get a crisp summary + vibe score (0-100)
- Share the result instantly

## Run it
```bash
npm install
npm start
```

Open http://localhost:3000 and start echoing.
